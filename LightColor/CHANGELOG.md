# Changelog

## 1.5.1
- The longship and drakkar don't show the key in their hover text anymore, since their lamp is never lit

## 1.5.0
- The `AdminOnly` setting on a server lets only its admins change colors and text glow, when the server has the mod installed (suggested by evers95)
- The `AdminOnlyHelmet` setting on a server lets only its admins color their helmet with the `Helmet` setting

## 1.4.1
- A black portal's trim now doesn't glow

## 1.4.0
- A shield generator keeps its color instead of flashing back to its own color
- A shield generator's dome takes its color

## 1.3.0
- Press L on a sign to make its text glow, with a halo, lit letters or an outline in a color, like `white 150% lit`

## 1.2.2
- The runes on a stone portal's frame take the portal's color, the way the carvings on a wood portal do

## 1.2.1
- Saving the config file no longer triggers the mod to write it back, so an editor with it open doesn't report it as changed
- Shows a message when the config file is reloaded

## 1.2.0
- Config changes take effect as soon as the file is saved; you don't need to restart Valheim or rejoin the world

## 1.1.0
- Traveling through a colored portal turns the swirl on the loading screen to the portal's color, then fades it ring by ring from the center outward to the color of the portal you arrive at
- Fixed portal colors not being saved in single player worlds

## 1.0.0
- Initial release
